# Project documentation

After completing an update to Forma, add a dated entry to `CHANGELOG.md` in the same change. Use the actual completion date in Europe/London time, put the newest entry first, and describe what was implemented, validation performed, and any outstanding limitations. Preserve historical entries. Multiple updates on the same date may have separate descriptive entries. Do not claim checks passed unless they were run successfully; for documentation-only changes, state that application tests were not rerun when applicable.
